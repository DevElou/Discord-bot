# Alain-Discord-Bot

Alain-Discord-Bot est un bot Discord développé en Python. Il permet d'automatiser certaines tâches sur un serveur Discord.

## Fonctionnalités
- Commandes personnalisées
- Interaction avec des API
- Gestion des utilisateurs

## Prérequis
- Python 3.x
- Un compte Discord avec un bot enregistré
- Un fichier `config.yml` contenant les informations de configuration

## Installation
1. Clonez ce dépôt :
   ```bash
   git clone https://github.com/votre-utilisateur/Alain-Discord-Bot.git
   cd Alain-Discord-Bot
   ```
2. Installez les dépendances :
   ```bash
   pip install -r requirements.txt
   ```
3. Configurez le fichier `config.yml` en ajoutant votre token Discord et d'autres paramètres nécessaires.

## Lancement du Bot
Pour exécuter le bot :
```bash
python main.py
```

## Utilisation avec Docker
Si vous souhaitez utiliser Docker :
```bash
docker build -t alain-discord-bot .
docker run -d alain-discord-bot
```
